## 项目概述

**BanG Dream! 记忆爆破 - Popin'Party的仓库对战** 是一款纯前端实现、无后端依赖的休闲记忆翻牌游戏。整体视觉、交互、动效完全贴合 BanG Dream! 少女乐团派对风格，提供精致的游戏体验。玩家将与 Popin'Party 的成员（多惠、有咲、香澄）进行对战，在翻牌的同时享受 BanG Dream! 的经典音乐！

## 游戏规则

### 基本规则

1. 玩家与 AI 轮流在卡片矩阵中翻牌
2. 目标是匹配相同的角色/乐器卡片
3. 配对成功获得 100 分，可继续翻牌
4. 翻到炸弹会扣除 1 点生命值 + 屏幕震动特效
5. 配对失败或翻到炸弹后换对方回合

### 胜利条件

- 所有卡片配对完成后，分数高者获胜
- 分数相同时，生命值高者获胜
- 一方生命值归 0 时直接判负

### 生命值系统

- 初始生命：3 点
- 翻到炸弹：-1 生命 + 屏幕震动特效 + 星星爆炸粒子

## 快速开始

### 环境要求

- 现代浏览器（Chrome 80+ / Edge 80+ / Firefox 75+ / Safari 13+）
- 无需后端服务器，纯前端运行
- 建议使用本地服务器以获得最佳音频体验

### 安装与运行

1. **克隆或下载项目**
   ```bash
   git clone <repository-url>
   cd Band_Flip
   ```

2. **使用本地服务器运行（推荐）**
   
   方法 1：使用 npx serve
   ```bash
   npx serve .
   ```
   
   方法 2：使用 Python
   ```bash
   python -m http.server 8000
   ```
   
   方法 3：使用 VS Code Live Server 扩展

3. **打开浏览器**
   访问 `http://localhost:3000`（或你设置的端口）

### 快速体验

直接双击 `index.html` 文件在浏览器中打开即可体验（部分浏览器可能因跨域限制无法播放音频）。

## AI 对手

### 难度选择

| 难度 | 网格大小 | 炸弹数量 | AI 思考时间 | AI 记忆能力 | AI 角色 |
|------|---------|---------|------------|------------|--------|
| 简单 | 3×3 | 1 | 1.5s | 无 | 多惠（完全随机） |
| 中等 | 4×4 | 2 | 1.0s | 记忆 3 张 | 有咲（智能匹配） |
| 困难 | 5×5 | 3 | 0.7s | 全部记忆 | 香澄（完美策略） |

### AI 策略说明

- **多惠（简单）**：完全随机翻牌，没有任何记忆能力，适合新手
- **有咲（中等）**：记忆最近 3 次翻牌位置，优先尝试匹配已知的卡片
- **香澄（困难）**：记忆所有翻开过的卡片，智能选择最优翻牌策略，低血量时会"激进"优先翻炸弹试图赌命

### 扩展开发

#### 添加新音乐

在 `MUSIC_CONFIG.songs` 数组中添加新歌曲：

```javascript
{
    file: 'asset/music/新歌曲.mp3',
    title: '歌曲标题',
    artist: '乐队名称',
    cover: 'asset/music/img/封面.png'
}
```

#### 添加新音效

在 `SOUND_CONFIG` 对象中添加新音效分类：

```javascript
newType: [
    'asset/SE/newType/sound1.mp3',
    'asset/SE/newType/sound2.mp3'
]
```

#### 添加新卡片

在 `CONFIG.cardImages` 中添加新卡片图片。
